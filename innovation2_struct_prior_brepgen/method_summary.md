# 创新点 2：弱条件结构先验驱动的构型图—B-Rep 层级几何生成方法

## 1. 方法原理与架构

本文提出一种**弱条件结构先验驱动的层级几何生成模型 (StructPriorBRepCVAE)**，其生成链路如下：

```
z + c (隐变量 + 类别)
    ↓
结构构型先验生成器 (StructuralPriorDecoder)
    ↓
生成 Gc* = (Vc*, Ec*, P*) [节点、关系、预测尺寸]
    ↓
主结构 face group layout 生成器 (FaceGroupLayoutDecoder)
    ↓
边界环 / B-Rep 拓扑生成器 (BoundaryTopologyDecoder)
    ↓
曲线曲面几何生成器 (CurveSurfaceGeometryDecoder)
    ↓
Constructive B-Rep Reconstructor (OpenCascade 重建实体)
    ↓
STEP / STL 输出
```

## 2. 输入特征与生成条件

* **最终输入**：
  * **$z \sim \mathcal{N}(0, I)$**：64 维随机高斯隐变量，用于控制相同类别构件的几何设计变差（如尺寸差异、厚度扰动）。
  * **$c$ (可选类别条件)**：航空构件的粗粒度类别（`l_angle`、`c_channel`、`z_beam`、`hat_stiffener`、`stiffened_panel`）。
* **重要声明**：
  在生成 (generate) 阶段，模型**严禁且无需直接输入**完整结构图（`configuration_graph`） and 真实参数表（`parameters`）。真实构型图 $G_c$ 与真实参数 $P$ 仅在训练阶段作为**多模态监督目标**，指导网络学习从低维隐空间到高维实体拓扑与几何控制的概率映射。
  构型图 $G_c^* = (V_c^*, E_c^*, P^*)$ 是模型解码生成的**结构先验中间表示层**，而不是用户输入。

## 3. 与 DTG 原始方法的学术区别

* **DTG (Direct B-Rep Generation) 局限性**：
  DTG 倾向于直接在低层 B-Rep 面、边几何点云及局部缝合拓扑上进行生成与拟合。对于航空复材薄壁加筋构件（带有大平直壁板、转弯过渡圆角、特定筋条数目），DTG 缺乏高层构型力学语义指导，极易生成无物理意义的交错曲面，或者拓扑自相交导致实体化缝合失败。
* **本方法改进点**：
  我们在生成链路中显式引入了**航空复材薄壁加筋构件的结构构型先验层 ($G_c$)**。网络先在顶层预测板壳各部分的工程功能角色（是面板、腹板还是圆角）以及全局尺度参数，以此作为指导去生成局部面布局与缝合拓扑。这一“构型先验驱动”的层级机制极大改善了航空大尺度薄壁件生成的合理性。

## 4. 第一创新点与第二创新点的科学衔接

* **第一创新点 (以分析和对齐为主)**：
  定义了图先验数学表示 $G_c = (V_c, E_c, P)$，并建立起了构型节点到实体主结构面片组的弱对齐映射机制 $M: V_c \to 2^F$。
* **第二创新点 (以生成和验证为主)**：
  在第一创新点对齐的数据集上，训练 StructPriorBRepCVAE。利用 $M$ 作为监督，实现了从隐状态 $z+c$ **端到端层级向下生成** $G_c^* \to$ 面布局 $\to$ 拓扑邻接 $\to$ 几何点云，并最终通过 CAD 重建器导出 STEP / STL 实体文件的完整流程。

## 5. 当前学术局限性与阶段边界

本程序为论文第二创新点的首版流程验证原型，其实验结论具有如下边界限制：
1. **CAD 重建闭环方式**：当前的 Constructive B-Rep Reconstructor 重建器仅支持 5 类规则化的航空复材薄壁构件。
2. **点云几何应用局限**：预测的 `face_wcs` (32x32) 和 `edge_wcs` (32点) 采样几何目前仅作为点云监督评估，尚未直接用于任意自由曲面的 trimmed surface 重建剪裁。
3. **真实工程与泛化证明**：本阶段结果仅用于验证“弱条件控制 -> 拓扑与参数生成 -> CAD 文件输出”这一层级生成管道的执行畅通性，不代表最终模型的泛化性能或真实工程构件的适航有效性。
